# 🌤️ Weather Forecast App

Modern responsive weather forecast web application built with HTML, CSS, and JavaScript using the Open-Meteo Forecast API.

---

# 📌 About The Project

The project was created as a team MVP application for the Web Technologies and Web Design course.

The application allows users to:
- search weather by city;
- view current temperature;
- see humidity and wind speed;
- view weather conditions;
- save the last searched city using localStorage.

The project features a modern glassmorphism UI and responsive design for mobile and desktop devices.
