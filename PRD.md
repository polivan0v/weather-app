# PRD — Weather Forecast App

## Мета продукту
Створити простий веб-застосунок для перегляду актуальної погоди в обраному місті.

## Цільова аудиторія
Користувачі, яким потрібно швидко дізнатися погоду.

## MVP Scope
- Пошук погоди за містом
- Виведення температури
- Виведення вологості
- Виведення швидкості вітру
- Виведення погодного стану
- Збереження останнього міста

- CSS
- JavaScript
